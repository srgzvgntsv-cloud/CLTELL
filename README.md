CLTELL — Telluric Line Correction using SLD
A program for recovering stellar spectra by modeling and removing telluric absorption. Implemented in Fortran without a graphical interface. All settings are provided through two configuration files.

Features
Direct modeling of the telluric spectrum based on standard atmospheric models and the HITRAN database.
Correction of line profiles using the Spectral Line Deconvolution (SLD) technique, which compensates for inaccuracies in atmospheric parameters.
Simultaneous treatment of multiple molecules (H₂O, O₂, CO₂, etc.) with independent SLD functions.
Account for the instrumental profile (Gaussian broadening).
Simultaneous fitting of telluric and stellar components.
Works with archival observations when accurate meteorological data are unavailable.

Requirements
Fortran compiler (gfortran, ifort, or any compiler compatible with Fortran 90).
Libraries: no external dependencies (except CXML.LIB, which is included with the distribution).
Operating system: Windows (pre-built .exe) or any OS with a Fortran compiler (Linux, macOS).

Installation and Build
Clone the repository or download the archive.
Open a terminal in the root folder of the project (e.g., CLTELL-main/).

Compile:
gfortran -O3 -o CLTELL.exe CLTELL.f90 *.f90 CXML.LIB
The executable CLTELL.exe will be created in the current folder.

Note: For Windows, you can use a pre-built binary from the bin/ folder if provided.

Usage
The program has no interactive input. All parameters are set in two configuration files located in the working folder next to the executable.

1. Main configuration file: SLD.config
Contains the parameters needed to process a specific stellar spectrum. Example:

Vega\                          ! Working directory
vega_normalized.dat            ! File-name (input spectrum)
none                           ! Height Relative Humidity File (none = not used)
2 1                            ! (1) 0 = by lines (lev-marq), 1 = by molecules, 2 = by lines (gold-sect)
                               ! (2) 0 = star+tell, 1 = tell, 2 = star
6000.0 6400.0                  ! Region (start and end of wavelength interval in Angstroms)
21                             ! Vsini (km/s)
100000                         ! Resolution
60                             ! Number of points SLD-profile
Vega                           ! File DataBase star lines (name of stellar line database)
1                              ! Number of groups by intensity
'O2  ': 0.3                    ! Groups: molecule name and initial SLD width (km/s)

2. Additional configuration file: config.ini
Contains fine-tuning settings of the algorithm. Example:

2              ! Number of iterations of correction of the strength of individual spectral lines
-3.0           ! Lower limit for refining the velocity of each individual line (km/s)
3.0            ! Upper limit for refining the velocity of each individual line (km/s)
0.0001         ! Lower range multiplier for searching the strength for an individual line
1000.0         ! Upper range multiplier for searching the strength for an individual line
1.0            ! Step of the SLD profile for star lines (km/s)
0.1            ! Step of the SLD profile for telluric lines (km/s)
0.01 0.0       ! Tikhonov regularization parameters
0              ! Observatory height in meters
2              ! Atmosphere Model Number: 1=Equatorial diurnal, 2=Mean latitude night, 3=Polar winter
2000           ! Altitude step in meters (for atmospheric grid)

Input Data Format
All files listed below must be placed in the working directory specified in SLD.config.

Observed spectrum – text file (or FITS) with two columns: wavelength (Å) and normalized flux.
Stellar line masks – generated by a separate utility (see the SLDinit/ folder). They include:
one unformatted file with the theoretical stellar line profile database (*.dbs);
one unformatted file with auxiliary information for the database (*.dir);
one text file with line information (three columns: wavelength (Å), line identifier, central depth) (*.lin).
In addition, you must unpack the file Hitran_database.par from the repository archive and place it in the folder with the executable.

Running
Simply run in a terminal (no arguments):
./CLTELL.exe
or on Windows:
CLTELL.exe

The program will print progress information during the iterations. Results will be written to the working directory:
*.no_tell – telluric-cleaned spectrum (wavelength (Å), normalized flux);
*.result – modeled observed spectrum (wavelength (Å), normalized flux);
*.sld – SLD profiles for each specified group of lines (velocity (km/s), normalized flux);
scale_abundances.dat – corrections for air molecular abundances (created automatically on first run; if the file already exists, the program will read data from it).

Example
The examples/ folder contains test data. To verify:
Go to the examples/ directory.
Make sure all necessary files are present.
Run the program:
../CLTELL.exe

Compare the obtained result (examples/vega_normalized.no_tell) with the original spectrum (examples/vega_normalized.dat).
